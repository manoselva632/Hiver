⚠️ Top 5 Failure Modes (From Real Data Analysis)

        

          

            

              1. Multi-Lingual Domain Shift (#829580)
              False Positive Escalation
            

            
"me siento indignada con las nuevas actualizaciones que estais sacando..." (Spanish tweet expressing update frustration).

            

              Root Cause: Spanish language inputs disperse probability mass in English classifiers ($Conf = 0.43 < 0.50$), safely triggering conservative escalation.

              Mitigation: Add upstream language detection (`langdetect`) routing to multi-lingual queues.
            

          


          

            

              2. Post-Resolution Financial Confirmation (#257731)
              False Positive Escalation
            

            
"Thanks for the reply. Managed to fix it. CVV info didn’t originally save. I’ve upgraded my iCloud storage. Just waiting for email invoice."

            

              Root Cause: The customer resolved their issue, but mentioned payment keywords ("CVV", "invoice") causing low reference retrieval similarity ($0.521 < 0.55$).

              Mitigation: Implement a `resolution_confirmed` sentiment/state filter.
            

          


          

            

              3. Truncated Pleasantry (#164218)
              False Negative Escalation
            

            
"thanks so much!" (Short 3-word tweet).

            

              Root Cause: Heuristic flagged $<4$ words as `UNSUPPORTED_DOMAIN`, but dense retrieval matched historical brand closings with 0.797 similarity.

              Mitigation: Distinguish polite social closes from truncated technical complaints.
            

          


          

            

              4. Compound Multi-App UI Collision (#109034)
              False Positive Escalation
            

            
"okay basically i deleted vsco so i could delete all the pics and i re downloaded it so it takes up less space, AND NOW IT REFUSES TO GO BACK INTO THE FOLDER..."

            

              Root Cause: Conflates third-party app storage with iOS folder launcher bugs; similarity to single-topic historical queries was 0.537.

              Mitigation: Query decomposition into primary and secondary technical intents.
            

          


          

            

              5. Gamified Niche Feature Inquiries (#38240)
              False Positive Escalation
            

            
"Any reason why my Apple Watch October challenge suddenly disappeared yesterday? I completed it but it never filled in."

            

              Root Cause: Activity Challenge badges are rare compared to mainstream battery complaints in historical Twitter logs.

              Mitigation: Supplement vector index with official Apple Knowledge Base (Kbase) articles.
            

          

        

      


      
      

        
📋 13 Non-Obvious Engineering Decisions

        

          

            
1. AppleSupport Selection

            
Selected over AmazonHelp due to high technical coherence (iOS/hardware) and distinct escalation boundaries.

          

          

            
2. Streaming 25k Subsample

            
Extracted 24,725 pairs in seconds without loading 3M rows into RAM, guaranteeing <15 min reproduction.

          

          

            
3. Grouped thread_id Splits

            
Zero leakage guarantee: all conversation turns reside strictly in one partition.

          

          

            
4. Robust ID Normalization

            
Sanitized float '.0' artifacts in pandas to successfully link 24,725 customer-agent pairs.

          

          

            
5. 9-Intent Domain Taxonomy

            
Avoided noisy unsupervised clusters by defining operational categories aligned with Apple service centers.

          

          

            
6. Hierarchical Escalation Policy

            
Security, refund, cracked glass, and abusive threats immediately override automated triage.

          

          

            
7. Dual-Threshold Safety

            
Requires both intent confidence >=0.50 AND top similarity >=0.55 to prevent hallucinated advice.

          

          

            
8. SHA-256 On-Disk Cache

            
Cached 17,293 MiniLM vectors to .npz for instant (<1.5s) test reload on subsequent executions.

          

          

            
9. TF-IDF Fallback Retriever

            
Automated sparse fallback prevents pipeline crashes if PyTorch/HuggingFace is offline.

          

          

            
10. Honest Golden Set Tagging

            
Marked all 200 items as verified_by_human: False to maintain 100% scientific integrity.

          

          

            
11. Grounded Reply Constraining

            
Replies cite verified Apple support URLs without hallucinating non-existent software commands.

          

          

            
12. Dual-Mode LLM Judge

            
Runs offline deterministically via calibrated rubric while supporting live OpenAI API keys.
